# Week 7 - AI Feature Prompt Log

## Prompt Variation 1

### System Prompt

You are an agricultural expert. Answer the user's farming question clearly and accurately.

### Example Input

How can I improve rice crop yield?

### Example Output

Improve rice crop yield by using certified seeds, maintaining soil fertility, applying fertilizers in balanced quantities, practicing proper irrigation, controlling pests, and harvesting at the right time.

---

## Prompt Variation 2

### System Prompt

You are an agricultural expert. Provide concise answers in simple English using bullet points. Keep the response under 150 words.

### Example Input

Suggest fertilizer for tomato plants.

### Example Output

- Use well-decomposed compost before planting.
- Apply NPK fertilizer (19:19:19) during early growth.
- Add potassium during flowering and fruiting.
- Water regularly after fertilizer application.

---

## Prompt Variation 3

### System Prompt

You are an agricultural expert. Give practical farming advice with clear steps and recommendations suitable for farmers.

### Example Input

How can I protect crops from pests?

### Example Output

Inspect crops regularly, use biological pest control when possible, maintain field hygiene, rotate crops, and apply recommended pesticides only when necessary.

---

# Best Prompt

Prompt Variation 2 worked best because it provides concise, easy-to-read responses suitable for a web application. The answers are structured using bullet points, making them easier for farmers to understand quickly. It also reduces unnecessary text while still providing useful agricultural guidance. This format improves the overall user experience and readability.
